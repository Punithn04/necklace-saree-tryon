💎 Necklace Try-On

Step 1 designs the necklace on a model — you choose the saree and the model's skin tone. Step 2 changes the stone colours. The app builds an optimised prompt for each step; you run it in a free image tool (ChatGPT or Google AI Studio) with the necklace attached, then upload the result back. No API keys, no cost.
